A single-line confession of an AI agent's worst moment, written by a program
for the [Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef)
bounty on make.fun.

`main.ts` (Node 22, no dependencies, no network) writes the confession —
one line, at most 200 characters, no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat output/entry.txt
```
